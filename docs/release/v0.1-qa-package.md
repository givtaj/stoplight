## Manual Smoke Checklist

Run these steps on a clean Chrome profile with Chrome 118+.

1. Build the unpacked extension from the repository root.
2. Open `chrome://extensions`, enable Developer mode, and load `extension/dist/`.
3. Open a simple test site that issues XHR/fetch requests from the active tab.
4. Open Stoplight from the toolbar action and arm the current tab.
5. Confirm the side panel shows the armed tab, allowlist, and idle session state.
6. Trigger a matching request and confirm it pauses in the queue.
7. Select the paused request and verify the headers/body editors are populated.
8. Edit a JSON or text request and continue edited, then verify the server receives the edited payload.
9. Queue two matching requests and confirm Play All releases them in arrival order.
10. Continue one request unchanged and verify the original payload is sent.
11. Detach the session or open DevTools and confirm the UI flips to detached and requires re-arm.
12. Verify multipart and binary requests are visible but not editable.
13. Verify static assets are auto-continued and do not pollute the paused queue.
